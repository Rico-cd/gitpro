# gitpro · GitHub 加速器

解决两件事：**浏览器打不开 GitHub 网页**，和 **clone / 下载太慢**。

核心是「把域名钉到真正能连的 IP 上」——不需要装证书，不需要配代理，浏览器直接生效。

---

## 一、网页加速（解决打不开）

### 为什么打不开

实测发现：GitHub 主页其实 1 秒就能返回，但页面里几十张图片全指向
`raw.githubusercontent.com`，这域名会解析出 4 个 IP，**其中 3 个是连不通的**。
浏览器撞上坏 IP 就卡住等 30 秒超时，页面就一直转圈。

> 实测数据：`github.com` 的 10 个 IP 只有 1 个可用，`raw` 是 1/4。

### 怎么用

1. 打开 gitpro，停在「**网页加速**」页
2. 等它自动检测完（约 10 秒，每行会显示优选 IP 和延迟）
3. 点「**一键加速**」→ 弹一次 UAC，允许
4. 刷新浏览器，直接就好

不需要重启电脑，不需要改浏览器设置。想撤销点「还原 hosts」即可。

### 安全性

- 只在 hosts 里加一段带明显标记的区块，**放在你原文件最前面**
  （因为 hosts 同一域名第一条生效，你原有的条目可能挡住它）
- 你原来写的行**一个都不删**，还原后与你原文件逐字节一致（已验证）
- 修改前自动备份为 `hosts.gitpro.bak`
- 只碰 GitHub 相关的 9 个域名，不动任何其他网站

## 二、下载 / Git 加速（解决慢）

切到「**下载 / Git**」页。

### 让 git clone 走加速

点「开启 Git 加速」后，直接 `git clone https://github.com/xxx/yyy.git` 就行，
不用改地址。关闭软件时会自动还原配置，不留残留。

### 转链接下载

粘贴链接 → 点「转换」→「复制」，用浏览器或下载工具打开：

```
原始：https://github.com/user/repo/archive/refs/heads/main.zip
加速：http://127.0.0.1:8888/https://github.com/user/repo/archive/refs/heads/main.zip
```

## 界面说明

**网页加速页**

| 列 | 含义 |
|---|---|
| 域名 | 要加速的 9 个 GitHub 域名 |
| 优选 IP | 实测能连、延迟最低的那个 |
| 延迟 | 首次连接耗时（TCP + TLS + 响应） |
| 可用 | 例如 `1/4` 表示 4 个候选 IP 里只有 1 个能连 |

颜色：绿 < 900ms，黄 < 1.8s，粉红更慢，红 = 无可用 IP。

**下载 / Git 页**

| 区域 | 内容 |
|---|---|
| 实时速度 | 当前速度、波动曲线、峰值 |
| 运行统计 | 下载总量、请求数、成功率、活跃连接 |
| 加速节点 | 节点延迟与可用状态，点一行可锁定 |
| Git 一键加速 | git 开关、链接转换 |
| 实时请求 | 时间、状态码、大小、耗时、通道、目标 |

## 原理

### 网页加速

```
浏览器请求 raw.githubusercontent.com
        │  系统 DNS 返回 4 个 IP
        ▼
   撞到坏的 IP → 卡 30 秒 ✗
        │
        ▼
  gitpro 逐个实测 9 个域名的所有候选 IP
  （TCP 连接 + TLS 握手 + HTTP 响应）
        │
        ▼
  把能连的 IP 写进 hosts，一个域名只留一个好 IP
        │
        ▼
   浏览器直连，稳定 1~2 秒 ✓
```

### 下载加速

本地在 `127.0.0.1:8888` 起反向代理，按域名分流：

- `raw` / `gist` / `objects` 等 CDN 域名 → 优先走公共加速节点
- `github.com` / `codeload` → 优先直连（实测快 10 倍）
- 某条路失败自动换下一条，并记住这个域名最快的通道
- 部分镜像会用 HTML 验证页冒充 200，识别后自动跳过

## 常见问题

**Q：点了「一键加速」没反应？**
UAC 弹窗可能被最小化了，看看任务栏。或者右键 exe →「以管理员身份运行」再点。

**Q：加速后过几天又变慢了？**
GitHub 的 IP 会轮换，旧 IP 可能失效。点「重新检测」再「一键加速」即可。
建议一周点一次。

**Q：会改坏我的 hosts 吗？**
不会。只加一个标记区块，你原有的行全部保留，还原后逐字节一致。还有 `hosts.gitpro.bak` 备份兜底。

**Q：需要装证书 / 改系统代理吗？**
都不需要。hosts 是系统自带机制，浏览器内核直接读，没有任何中间人解密。

**Q：关掉 gitpro 后加速还在吗？**
hosts 加速是持久的，关掉软件也生效。下载加速（本地代理）需要软件开着。

**Q：杀毒软件报警？**
因为要写 hosts + 请求管理员权限，属于正常行为。源码全在 `code/gitpro.py`，可以自己审。
